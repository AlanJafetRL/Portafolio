Fullstack - Aplicación web con sistema de registro e información para evento académico


Actualmente en evolución, en espera de retroalimentación para continuar con mejoras.

Plataforma web desarrollada con Angular y .NET que integra dos aplicaciones en un solo sitio: una para los asistentes del evento y otra para el equipo organizador (staff).
La primera permite consultar información clave sobre conferencias, talleres y eventos recreativos, así como realizar el preregistro y registro al evento.
La segunda funciona como un sistema de control con autenticación por roles (admin/staff) y permite gestionar usuarios, alumnos registrados, asistencias, reportes y más contenido editable.

El sistema fue diseñado de forma escalable, implementa arquitectura por capas, buenas prácticas de seguridad, validaciones, separación de responsabilidades y comunicación eficiente entre frontend y backend.
La autenticación se gestiona con JWT y los menús y accesos se ajustan dinámicamente según el rol del usuario.

El backend está construido con .NET 8, ASP.NET Core, Entity Framework Core y SQL Server. La API RESTful aplica principios SOLID, patrón DTO, y control de acceso mediante autorización por roles.
El frontend está construido con Angular, Angular Material y RxJS, incluyendo animaciones, lazy loading, guards, interceptores, formularios reactivos y diseño responsivo.

Desplegado en Azure como una versión funcional para presentación al cliente y pruebas en entorno real.


Tecnologías: Angular, RxJS, TypeScript, SCSS, Angular Material, .NET 8, ASP.NET Core, Entity Framework, SQL Server, JWT, Azure
